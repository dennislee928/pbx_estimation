財務假設檢定 — 汰換實體 PBX

以真實市場價格建構之蒙地卡羅 TCO 模型進行單尾單樣本 t 檢定；H0 = 汰換不具財務合理性（NPV(續用-汰換) 平均值 <= 0）。

模型假設（真實價格）

  • 折現率：3%
  • 實體 PBX 前期資本支出：$500–$1000 / seat
  • 實體年度維護：15–20% 資本支出
  • 雲端／IP-PBX 訂閱：$15–$35 / seat / mo
  • 每市場蒙地卡羅抽樣數：20,000

Delta 為每席位 NPV(續用 - 汰換)：正值代表汰換可省錢。在純營運成本與 3% 折現率下，雲端訂閱費用流高於實體維護費，故 3/5/10 年皆無法拒絕 H0。

假設檢定結果

單尾檢定 H₀：汰換不具財務合理性（NPV(續用 − 汰換) 平均值 ≤ 0），對立 H₁：Δ > 0（汰換較便宜）。p < 0.05 時拒絕 H₀。

註：此處每個 Δ 皆為負且 p ≈ 1.000——這並非錯誤。對 Δ > 0 的單尾檢定回傳 p ≈ 1，正是因為證據方向相反：僅就經常性現金成本，雲端訂閱費用流高於實體維護費，故各期間皆無法拒絕 H₀。此模型未計入 IT 人力、硬體汰換、停機與被迫的 EOL 遷移，這也是業界『全載』TCO 研究仍偏好雲端的原因——詳見報告筆記本的論述。
